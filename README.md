## 📝 About the Project

**Motors** is a web-based application developed to represent and manage operations related to a motor/car dealership.  
The project focuses on creating a modern, responsive, and user-friendly interface using the latest frontend technologies.

It demonstrates practical implementation of component-based architecture, responsive UI design, and clean code practices suitable for real-world automotive or dealership platforms.

## ⚙️ How to Run the Project Locally

### Prerequisites

- Node.js and npm installed  
  👉 Install using nvm: https://github.com/nvm-sh/nvm#installing-and-updating

### Steps

```sh
# Clone the repository
git clone https://github.com/harsha2511/Motors.git

# Navigate to the project directory
cd Motors

# Install dependencies
npm install

# Start the development server
npm run dev
